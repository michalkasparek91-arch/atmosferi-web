How we work together.

01 · Content and brief

We review your current website, selected projects, intended audience and the enquiries you want to receive. This defines the page structure and what content is missing.

02 · Design and build

We agree the visual direction, then develop the website around real project material. Desktop and mobile layouts are considered together, including navigation, typography and image loading.

03 · Launch and handover

We review content, links, forms and the mobile experience before launch. Page titles, descriptions, crawlable project pages and image descriptions form part of the technical foundation.

From Prague, across borders.

Atmosferi is based in Prague, Czechia, and works remotely with architecture practices worldwide, including the United States, Switzerland and Norway. We agree communication, review times, site languages and the required deliverables at the start of each project.

Questions before a project.

Can you redesign an existing architecture website?

Yes. We can start by reviewing your project archive, page structure and current presentation. Existing material can be reused where it fits; the redesign scope is agreed before work begins.

Can the website have several languages?

Yes. We can plan separate language URLs, translated content and language links. The brief defines the languages and who supplies or reviews each translation, including regional terminology.

Do you also create architectural visualisations?

Yes. Renders, architectural films and 360° views can be included where they help explain the project. They can also be a separate commission.

How much does an architecture website cost?

The price depends on the number of layouts, project content, languages, editing tools and any new imagery. The pricing page explains the current starting scope; a specific brief receives an individual proposal.
